# 运动世界校园 · 一键跑步

Windows 上一键完成当天校园跑的工具。仓库内提供两个版本，按需选择：

| 版本 | 形态 | 依赖 | 适用场景 |
|---|---|---|---|
| [**v2.0 免安装版**](./v2.0-纯Windows版/) | 单文件 `一键跑步.exe`（12 MB） | 无（无需 Python / 模拟器 / adb） | **推荐**，下载双击即用 |
| [v1.0 MuMu 版](./v1.0-MuMu版/) | Python 源码 + 启动脚本 | MuMu 模拟器 6、Zygisk Next、LSPosed/Vector、HMA、LocationSpoofer、SportSniffer、Python 3.11.9、pycryptodome 4.1.0 | 历史归档，仅供研究参考 |

## v2.0 快速开始

1. 下载 [`v2.0-纯Windows版/一键跑步.exe`](./v2.0-纯Windows版/一键跑步.exe)，放到可写目录（不要放 `Program Files`）；
2. 双击 → 「登录账号」→ 填手机号、密码 → 浏览器里拖一次滑块；
3. 点「① 一键完成今天」，等核验结果；点「② 核对数据」看服务端回执。

完整说明、命令参考、排障与参数区间见 [v2.0 README](./v2.0-纯Windows版/README.md)。

## 版本差异

| | v1.0（MuMu 版） | v2.0（免安装版） |
|---|---|---|
| 登录方式 | 需在模拟器内登录 App，再从已登录实例取令牌 | 手机号 + 密码直接登录（自动过滑块） |
| 环境要求 | 安卓模拟器 + Root + 多个 LSPosed 模块 | 仅一个 exe |
| 部署耗时 | 约 40–60 分钟 | 约 1 分钟 |
| 账号切换 | 需在模拟器内切换 | 界面下拉框 / `switch` 命令 |
| 分发形式 | 源码 | 加固后的可执行文件 |

## 通用说明

- **凭据安全**：`credentials.bin` 用 Windows DPAPI 加密，仅本机当前用户可解；密码不落盘。仓库内不含任何真实账号信息。
- **使用边界**：仅限本人账号，遵守学校体育考核规定与运动世界校园用户协议；因使用产生的成绩无效、账号风险等后果由使用者承担。
- **不含第三方组件**：仓库不包含模拟器、Root 框架、位置模块等第三方软件的源码或二进制，仅提供版本说明与官方获取渠道。
- **开发记录**：仓库不收录开发期的分析与调试记录，仅提供可运行产物与使用文档。
