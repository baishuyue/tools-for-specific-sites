# 优学院刷课脚本（DGUT 优化版）

适配东莞理工学院优学院网页端的 Tampermonkey（油猴）脚本：**自动静音播放、自动翻页、自动做练习题、修改播放速率**。

本项目是在 [Brush-JIM](https://greasyfork.org/zh-CN/users/br%E6%89%8B) 的《优学院自动静音播放、自动做练习题、自动翻页、修改播放速率（改）》与 [luluzzy.](https://greasyfork.org/zh-CN/scripts/555722-dgut-ulearning-tool) 的《DGUT Ulearning Tool》（MIT 协议）基础上二次开发重构的优化版，接口与页面结构针对 DGUT 部署环境重新适配。

- 脚本文件：[`优学院DGUT版-1.6.10.user.js`](./优学院DGUT版-1.6.10.user.js)
- 生效页面：`https://ua.dgut.edu.cn/learnCourse/learnCourse.html*`（课程学习页）

## 功能特性

| 分类 | 功能 |
|---|---|
| 视频控制 | 自动播放、自动翻页、自动静音、自动调整速率 |
| 倍速调节 | 1–15 倍任意调节（面板按钮加速/减速，或直接输入数值） |
| 自动作答 | 单选题、多选题、判断题、填空题（可分别开关），支持"显示答案" |
| 稳定性 | 播放失败自动重启、翻页失败按钮兜底、最大重试次数控制 |
| 面板 | 可拖动悬浮控制面板、操作日志实时显示、设置一键保存（localStorage 持久化，刷新不丢失） |

## 安装流程

### 第一步：安装 Tampermonkey 浏览器扩展

在浏览器扩展商店搜索并安装 **Tampermonkey（油猴）**：

- Chrome：[Chrome 应用商店](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)
- Edge：[Edge 加载项](https://microsoftedge.microsoft.com/addons/detail/tampermonkey/iikmkjmpaadaobahmlepeloendndfphd)
- Firefox：[Firefox 附加组件](https://addons.mozilla.org/firefox/addon/tampermonkey/)

### 第二步：安装本脚本

**方式 A —— 从本仓库安装（推荐）**

1. 打开本仓库中的 [`优学院DGUT版-1.6.10.user.js`](./优学院DGUT版-1.6.10.user.js)，点击 Raw / 原始文件；
2. 浏览器会自动唤起 Tampermonkey 的脚本安装页，点击"安装"。

**方式 B —— 手动粘贴**

1. 点击浏览器右上角 Tampermonkey 图标 → "添加新脚本"；
2. 清空编辑器，把 `优学院DGUT版-1.6.10.user.js` 的全部内容粘贴进去；
3. `Ctrl + S` 保存。

### 第三步：验证安装

打开 Tampermonkey 管理面板，能看到"优学院DGUT版"且状态为已启用即安装成功。

## 使用流程

1. **进入课程学习页**：登录学校优学院，进入任意课程的**视频学习页面**（地址形如 `ua.dgut.edu.cn/learnCourse/learnCourse.html...`）；
2. **打开控制面板**：页面右侧会自动出现可拖动的"**DGUT 优学院助手**"悬浮面板（顶部"拖动调整位置"可移动面板）；
3. **按需勾选功能**：

   | 面板选项 | 说明 |
   |---|---|
   | 自动播放/翻页 | 视频播完自动进入下一页 |
   | 自动静音 | 加载视频后自动静音播放 |
   | 自动调整速率 | 按设定倍速自动接管播放器速率 |
   | 播放速率 | 1–15 之间的数值，也可用"➕加速 / ➖减速"按钮调节 |
   | 自动作答(总开关) | 控制下面所有答题功能的总入口 |
   | 显示答案 | 作答时在页面上展示答案 |
   | 自动答选择题 / 多选题 / 判断题 / 填空题 | 分别对应题型的自动作答开关 |

4. **保存设置**：调整完成后点击"**保存设置**"，配置保存在浏览器 localStorage 中，下次打开自动生效；
5. **暂停/恢复**：点击"⏸️ 暂停脚本"可随时暂停全部自动化动作，按钮变为"▶️ 继续脚本"后点击恢复；
6. **查看日志**：面板底部"操作日志"区域实时显示翻页、答题、重启等动作记录，可用于确认脚本工作状态。

脚本运行期间无需值守；页面发生跳转或刷新后面板会自动重建并延续已保存的设置。

## 注意事项

- **倍速风险**：过高倍速、长时间挂机可能触发平台风控或被任课教师发现，建议合理设置倍速、优先用于非核心课程，使用风险自负；
- **仅限个人学习**：本脚本仅供个人学习交流使用，禁止商用；
- **答案准确性**：自动作答的答案来自页面接口返回，个别题目可能存在偏差，重要习题请自行核对；
- **页面改版**：若学校优学院页面结构改版导致功能失效，请关注本仓库更新。

## 常见问题

**面板没有出现？**
确认当前页面地址属于 `ua.dgut.edu.cn/learnCourse/learnCourse.html`，且 Tampermonkey 中本脚本处于启用状态；尝试刷新页面。

**倍速不生效？**
勾选"自动调整速率"，并将播放速率设置为合法区间（1–15）；部分浏览器对高速播放有限制，可逐级上调。

**视频播放失败？**
脚本会按最大重试次数自动重启播放（面板有提示"播放失败时将自动重启"），多次失败请检查网络后刷新页面。
