# 针对特定站点的各项小工具

面向特定站点（以东莞理工学院优学院 / uLearning 为主）的各类实用小工具合集。

每个工具独立成目录，自带完整使用文档，可单独取用。所有工具均基于**本人学生账号**的官方客户端接口实现，不涉及任何伪造身份、绕过服务端校验的行为。

## 工具列表

| 工具 | 说明 | 形态 |
|---|---|---|
| [签到器](./签到器/) | 优学院课程 / 活动查询与签到助手，支持定位签到（多坐标系）、一键签到、监听模式 | 源码（Python）+ Windows 版 + Android 版 |
| [优学院刷课脚本](./优学院刷课脚本/) | 优学院网页端油猴（Tampermonkey）脚本：自动静音播放、自动翻页、自动做练习题、倍速调节 | 油猴脚本（.user.js） |

## 通用说明

- **配置安全**：所有工具的账号配置文件（`ulearning-cmd.json`）在本仓库中均为空白模板。请勿将填有真实账号、密码或令牌的配置文件提交到任何公开仓库。
